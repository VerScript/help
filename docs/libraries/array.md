# Array — Standard Library

> **Category**: `library` | **Subcategory**: Standard Library

## Overview
Functional array manipulation: map, filter, reduce, sort, and zip.

## Syntax
```verscript
load Array
Array.map(arr, fn)
Array.filter(arr, fn)
Array.sort(arr)
```

## Example
```verscript
load Array
Array.map(arr, fn)
Array.filter(arr, fn)
display "Library initialized." ?color=#00FFCC
```
