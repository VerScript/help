# Color

**Category:** LIBRARY | **Subcategory:** Standard Library

## Summary
ANSI 24-bit Truecolor terminal palette generation, RGB/HSL conversions, and gradients.

## Syntax
```verscript
load Color
Color.rgb(r, g, b)
Color.hex("#00FFCC")
```

## Runnable Code Example
```verscript
load Color
Color.rgb(r, g, b)
Color.hex("#00FFCC")
display "Library initialized." ?color=#00FFCC
```
