# Time

**Category:** LIBRARY | **Subcategory:** Standard Library

## Summary
High-resolution monotonic timer, epoch timestamps, sleep delay, and date formatting.

## Syntax
```verscript
load Time
Time.now()
Time.sleep(ms)
Time.epoch()
```

## Runnable Code Example
```verscript
load Time
Time.now()
Time.sleep(ms)
display "Library initialized." ?color=#00FFCC
```
