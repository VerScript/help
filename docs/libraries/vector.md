# Vector — Standard Library

> **Category**: `library` | **Subcategory**: Standard Library

## Overview
High-speed 2D, 3D, and n-dimensional geometric vector operations (dot, cross, norm).

## Syntax
```verscript
load Vector
Vector.dot(u, v)
Vector.norm(v)
Vector.cross(u, v)
```

## Example
```verscript
load Vector
Vector.dot(u, v)
Vector.norm(v)
display "Library initialized." ?color=#00FFCC
```
