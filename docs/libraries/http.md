# Http — Standard Library

> **Category**: `library` | **Subcategory**: Standard Library

## Overview
High-level HTTP/HTTPS client for GET, POST, and REST API requests.

## Syntax
```verscript
load Http
Http.get(url)
Http.post(url, body)
```

## Example
```verscript
load Http
Http.get(url)
Http.post(url, body)
display "Library initialized." ?color=#00FFCC
```
