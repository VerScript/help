# Random

**Category:** LIBRARY | **Subcategory:** Standard Library

## Summary
Cryptographic and pseudo-random distributions: gaussian, uniform, choice, shuffle.

## Syntax
```verscript
load Random
Random.int(min, max)
Random.float()
Random.choice(arr)
```

## Runnable Code Example
```verscript
load Random
Random.int(min, max)
Random.float()
display "Library initialized." ?color=#00FFCC
```
