# Math — Standard Library

> **Category**: `library` | **Subcategory**: Standard Library

## Overview
Trigonometric, logarithmic, and advanced mathematical operations.

## Syntax
```verscript
load Math
Math.sin(x)
Math.cos(x)
Math.pow(a, b)
```

## Example
```verscript
load Math
Math.sin(x)
Math.cos(x)
display "Library initialized." ?color=#00FFCC
```
