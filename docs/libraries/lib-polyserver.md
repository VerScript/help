# Polyserver

**Category:** LIBRARY | **Subcategory:** Standard Library

## Summary
Dynamic microservice gateway binding internal VerScript endpoints.

## Syntax
```verscript
load Polyserver
Polyserver.route("/api", handler)
```

## Runnable Code Example
```verscript
load Polyserver
Polyserver.route("/api", handler)
display "Library initialized." ?color=#00FFCC
```
