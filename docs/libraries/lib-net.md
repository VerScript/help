# Net

**Category:** LIBRARY | **Subcategory:** Standard Library

## Summary
Low-level TCP/UDP socket network communications.

## Syntax
```verscript
load Net
Net.connect(host, port)
Net.listen(port)
```

## Runnable Code Example
```verscript
load Net
Net.connect(host, port)
Net.listen(port)
display "Library initialized." ?color=#00FFCC
```
