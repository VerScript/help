# Sys — Standard Library

> **Category**: `library` | **Subcategory**: Standard Library

## Overview
Operating system inspection: environment variables, arguments, platform, and exit codes.

## Syntax
```verscript
load Sys
Sys.env("PATH")
Sys.args()
Sys.exit(0)
```

## Example
```verscript
load Sys
Sys.env("PATH")
Sys.args()
display "Library initialized." ?color=#00FFCC
```
