# String — Standard Library

> **Category**: `library` | **Subcategory**: Standard Library

## Overview
String formatting, regex pattern evaluation, slicing, and transformations.

## Syntax
```verscript
load String
String.split(s, delim)
String.replace(s, pat, repl)
```

## Example
```verscript
load String
String.split(s, delim)
String.replace(s, pat, repl)
display "Library initialized." ?color=#00FFCC
```
