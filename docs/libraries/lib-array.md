# Array

**Category:** LIBRARY | **Subcategory:** Standard Library

## Summary
Functional array manipulation: map, filter, reduce, sort, and zip.

## Syntax
```verscript
load Array
Array.map(arr, fn)
Array.filter(arr, fn)
Array.sort(arr)
```

## Runnable Code Example
```verscript
load Array
Array.map(arr, fn)
Array.filter(arr, fn)
display "Library initialized." ?color=#00FFCC
```
