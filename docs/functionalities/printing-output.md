# How to Print and Format Output in VerScript

> **Category**: `functionality` | **Subcategory**: I/O

## Overview
Methods for streaming formatted text, numbers, arrays, and Truecolor ANSI styled messages to the terminal.

## Example
```verscript
display "Default white text"
display "Cyan highlighted text" ?color=#00FFCC
display "Loading: " ?inline ?color=#38bdf8
display "Done!" ?color=#22c55e
```
