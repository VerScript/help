# Loops, Ranges, and Iteration

**Category:** FUNCTIONALITY | **Subcategory:** Iteration

## Summary
Iterating ranges with 'from...to', stepping with 'by', repeating fixed counts, and iterating arrays with 'in'.

## Syntax
```verscript
undefined
```

## Runnable Code Example
```verscript
! Loop with step
loop i from 0 to 10 by 2:
  display "Even number: " + i ?color=#38bdf8

! Array iteration
loop item in ["alpha", "beta", "gamma"]:
  display "Item: " + item ?color=#00FFCC
```
