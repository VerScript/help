# round — Nearest Integer Rounding

**Category:** Built-in Math Function  
**Identifier:** `round`

---

## Summary
Rounds a number to the nearest integer value using standard half-up rounding.

## Syntax
```verscript
round(value)
```

**Parameters:** value (num)  
**Returns:** num (nearest integer)  
**Paired Keywords:** `floor, ceil`

## Code Example
```verscript
display round(7.5)  ! Outputs 8
```
