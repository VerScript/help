# render — Trigger Frame Rasterization

**Category:** Graphics & Rendering  
**Identifier:** `render`

---

## Summary
Initiates rasterization of active scene geometry and visual elements onto the screen canvas.

## Syntax
```verscript
render(scene, camera)
```

**Parameters:** scene (scene object), camera (camera object)  
**Returns:** None  
**Paired Keywords:** `screen, scene, camera, frame`

## Code Example
```verscript
render(mainScene, mainCamera)
```
