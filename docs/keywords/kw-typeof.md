# typeof

**Category:** KEYWORD | **Subcategory:** Type System & Reflection

## Summary
Returns the string primitive or class type name of any evaluated operand.

## Syntax
```verscript
typeof <expression>
```

## Parameters / Arguments
- `expression` *(any)*: undefined

## Runnable Code Example
```verscript
def printType(x):
  display "Type is: " + (typeof x) ?color=#00FFCC
```
