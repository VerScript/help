# exp — Natural Exponential Function

**Category:** Built-in Math Function  
**Identifier:** `exp`

---

## Summary
Computes e raised to the power of x ($e^x$).

## Syntax
```verscript
exp(x)
```

**Parameters:** x (num)  
**Returns:** num ($e^x$)  
**Paired Keywords:** `ln, log2`

## Code Example
```verscript
display exp(1)  ! Approximately 2.71828
```
