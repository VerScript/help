# alias

**Category:** KEYWORD | **Subcategory:** Declaration & Metaprogramming

## Summary
Creates an alternate identifier or shortcut alias for existing keywords, standard libraries, or procedures.

## Syntax
```verscript
alias <new_name> : <existing_target>
```

## Parameters / Arguments
- `new_name` *(identifier)*: undefined
- `existing_target` *(identifier)*: undefined

## Runnable Code Example
```verscript
alias echo : display
echo "Hello via echo alias!" ?color=#38bdf8
```
