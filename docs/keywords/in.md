# in — Membership Predicate & Range Iterator

**Category:** Collection & Range Traversal  
**Identifier:** `in`

---

## Summary
Specifies range or collection iteration in loop headers and tests for element inclusion.

## Syntax
```verscript
for element in collection:
    ...
```

**Parameters:** element (identifier), collection (array, range, or string)  
**Returns:** Iterates through members  
**Paired Keywords:** `for, iterate, step, range`

## Code Example
```verscript
for num in [10, 20, 30]:
    display "Number: " + num
```
