# complex — Complex Number Constructor

**Category:** Complex Number Primitive  
**Identifier:** `complex`

---

## Summary
Instantiates a complex number with real and imaginary parts ($a + bi$).

## Syntax
```verscript
complex(real, imag) or 3 + 4i
```

**Parameters:** real (num), imag (num)  
**Returns:** complex number instance  
**Paired Keywords:** `real, imag, conj`

## Code Example
```verscript
z : complex(3, 4)
display "Complex: " + z
```
