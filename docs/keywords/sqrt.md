# sqrt — Square Root

**Category:** Built-in Math Function  
**Identifier:** `sqrt`

---

## Summary
Computes the principal non-negative square root of a number.

## Syntax
```verscript
sqrt(x)
```

**Parameters:** x (non-negative num)  
**Returns:** num ($sqrt{x}$)  
**Paired Keywords:** `rt, hypot`

## Code Example
```verscript
display sqrt(144)  ! Outputs 12
```
