# draw — Immediate-Mode Shape Rendering

**Category:** Immediate Graphics  
**Identifier:** `draw`

---

## Summary
Issues immediate 2D drawing instructions for geometric primitives.

## Syntax
```verscript
draw(shape, x, y)
```

**Parameters:** shape (rect, circle, line), coordinates  
**Returns:** None  
**Paired Keywords:** `rect, circle, fill, stroke`

## Code Example
```verscript
draw rect(100, 100, 50, 50) ?fill=#00FFCC
```
