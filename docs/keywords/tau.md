# tau — Full Turn Circle Constant (2π)

**Category:** Math Constant  
**Identifier:** `tau`

---

## Summary
The circle constant representing one full turn in radians ($2pi approx 6.283185307179586$).

## Syntax
```verscript
tau
```

**Parameters:** None  
**Returns:** num (6.283185307179586)  
**Paired Keywords:** `pi, sin, cos`

## Code Example
```verscript
angle : tau * 0.25  ! Quarter turn (90 deg)
```
