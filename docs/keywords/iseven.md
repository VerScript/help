# isEven / iseven — Functional Even Predicate

**Category:** Numeric Predicate  
**Identifier:** `isEven`

---

## Summary
Functional call checking if an integer is even.

## Syntax
```verscript
isEven(n)
```

**Parameters:** n (int)  
**Returns:** bool (true if divisible by 2)  
**Paired Keywords:** `isOdd, is even`

## Code Example
```verscript
display isEven(10)  ! true
```
