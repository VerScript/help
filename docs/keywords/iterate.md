# iterate — Explicit Sequence Driver

**Category:** Loop Construct  
**Identifier:** `iterate`

---

## Summary
Initiates explicit iteration across numeric ranges or collection items.

## Syntax
```verscript
iterate from start to end by step:
    ...
```

**Parameters:** start (num), end (num), step (num)  
**Returns:** Executes body for each iteration  
**Paired Keywords:** `from, to, by, step, loop`

## Code Example
```verscript
iterate from 1 to 5:
    display "Step count"
```
