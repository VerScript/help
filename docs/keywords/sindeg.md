# sinDeg / sindeg — Trigonometric Sine (Degrees)

**Category:** Trigonometric Function  
**Identifier:** `sinDeg`

---

## Summary
Computes the sine of an angle directly specified in degrees.

## Syntax
```verscript
sinDeg(degrees)
```

**Parameters:** degrees (num)  
**Returns:** num (-1.0 to 1.0)  
**Paired Keywords:** `cosDeg, degToRad`

## Code Example
```verscript
display sinDeg(90)  ! Outputs 1
```
