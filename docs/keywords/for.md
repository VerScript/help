# for — VerScript Language Keyword

> **Category**: `keyword` | **Subcategory**: Iteration

## Overview
Iterator loop syntax for stepping through countable sequences.

## Syntax
```verscript
for <i = 0; i < N; i = i + 1>:
  <body>
```

## Example
```verscript
for <i = 0; i < 3; i = i + 1>:
  display i
```
