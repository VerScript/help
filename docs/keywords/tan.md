# tan — Trigonometric Tangent (Radians)

**Category:** Trigonometric Function  
**Identifier:** `tan`

---

## Summary
Computes the trigonometric tangent of an angle in radians.

## Syntax
```verscript
tan(radians)
```

**Parameters:** radians (num)  
**Returns:** num (tangent ratio)  
**Paired Keywords:** `sin, cos`

## Code Example
```verscript
display tan(pi / 4)  ! Approximately 1
```
