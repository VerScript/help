# floor — Floor Rounding

**Category:** Built-in Math Function  
**Identifier:** `floor`

---

## Summary
Rounds a numeric value downward to the nearest integer.

## Syntax
```verscript
floor(value)
```

**Parameters:** value (num)  
**Returns:** num (floor integer)  
**Paired Keywords:** `ceil, round`

## Code Example
```verscript
val : 8.89
display floor(val)  ! Outputs 8
```
