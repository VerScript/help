# title — Set Window or Document Title

**Category:** Window / Terminal Metadata  
**Identifier:** `title`

---

## Summary
Sets the application window title or terminal tab title string.

## Syntax
```verscript
title(title_string)
```

**Parameters:** title_string (str)  
**Returns:** None  
**Paired Keywords:** `terminal, config`

## Code Example
```verscript
title "VerScript Simulator v2.0"
```
