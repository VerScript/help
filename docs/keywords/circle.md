# circle — 2D Circle Geometry Primitive

**Category:** Geometry Primitive  
**Identifier:** `circle`

---

## Summary
Constructs a 2D circle with center coordinates and radius.

## Syntax
```verscript
circle(centerX, centerY, radius)
```

**Parameters:** centerX (num), centerY (num), radius (num)  
**Returns:** circle geometry shape  
**Paired Keywords:** `draw, rect, fill`

## Code Example
```verscript
coin : circle(150, 150, 25)
```
