# rect — 2D Rectangle Geometry Primitive

**Category:** Geometry Primitive  
**Identifier:** `rect`

---

## Summary
Constructs a 2D rectangular shape with position, width, and height.

## Syntax
```verscript
rect(x, y, width, height)
```

**Parameters:** x (num), y (num), width (num), height (num)  
**Returns:** rect geometry shape  
**Paired Keywords:** `draw, circle, fill`

## Code Example
```verscript
box2d : rect(50, 50, 200, 100)
```
