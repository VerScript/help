# line — Vector Line Segment

**Category:** Geometry Primitive  
**Identifier:** `line`

---

## Summary
Constructs a line segment between two coordinate points.

## Syntax
```verscript
line(x1, y1, x2, y2)
```

**Parameters:** Start and end coordinates  
**Returns:** line geometry shape  
**Paired Keywords:** `draw, stroke`

## Code Example
```verscript
ray : line(0, 0, 100, 100)
```
