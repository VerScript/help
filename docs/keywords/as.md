# as — VerScript Language Keyword

> **Category**: `keyword` | **Subcategory**: Type Casting & Aliasing

## Overview
Casts an expression to a target type or binds an imported module alias.

## Syntax
```verscript
<expr> as <Type>
import <mod> as <alias>
```

## Example
```verscript
set n : "123" as num
```
