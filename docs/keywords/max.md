# max — Maximum Value Determination

**Category:** Built-in Math Function  
**Identifier:** `max`

---

## Summary
Returns the greater of two values, or the largest item in an array.

## Syntax
```verscript
max(a, b) or max(array)
```

**Parameters:** a (num), b (num) or array of nums  
**Returns:** num (largest value)  
**Paired Keywords:** `min, clamp`

## Code Example
```verscript
display max(14, 29)  ! Outputs 29
```
