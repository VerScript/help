# min — Minimum Value Determination

**Category:** Built-in Math Function  
**Identifier:** `min`

---

## Summary
Returns the lesser of two values, or the smallest item in an array.

## Syntax
```verscript
min(a, b) or min(array)
```

**Parameters:** a (num), b (num) or array of nums  
**Returns:** num (smallest value)  
**Paired Keywords:** `max, clamp`

## Code Example
```verscript
display min(14, 29)  ! Outputs 14
```
