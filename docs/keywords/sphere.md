# sphere — 3D Spherical Mesh Primitive

**Category:** 3D Mesh Primitive  
**Identifier:** `sphere`

---

## Summary
Constructs a 3D spherical mesh with a defined radius and radial segments.

## Syntax
```verscript
sphere(radius, segments)
```

**Parameters:** radius (num), segments (int)  
**Returns:** 3D spherical mesh  
**Paired Keywords:** `box, spawn, scene`

## Code Example
```verscript
orb : sphere(1.5, 32)
```
