# else — Alternative Execution Branch

**Category:** Branching Clause  
**Identifier:** `else`

---

## Summary
Executes an alternate block of code when an preceding if or unless condition is not satisfied.

## Syntax
```verscript
if condition:
    ...
else:
    ...
```

**Parameters:** None  
**Returns:** None  
**Paired Keywords:** `if, then, unless`

## Code Example
```verscript
level : 5
if level > 10:
    display "Veteran"
else:
    display "Novice" ?color=#f59e0b
```
