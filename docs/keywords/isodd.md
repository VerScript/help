# isOdd / isodd — Functional Odd Predicate

**Category:** Numeric Predicate  
**Identifier:** `isOdd`

---

## Summary
Functional call checking if an integer is odd.

## Syntax
```verscript
isOdd(n)
```

**Parameters:** n (int)  
**Returns:** bool (true if odd)  
**Paired Keywords:** `isEven, is odd`

## Code Example
```verscript
display isOdd(7)  ! true
```
