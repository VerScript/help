# hcf — Highest Common Factor

**Category:** Built-in Math Function  
**Identifier:** `hcf`

---

## Summary
Canonical alias for gcd.

## Syntax
```verscript
hcf(a, b)
```

**Parameters:** a (int), b (int)  
**Returns:** int  
**Paired Keywords:** `gcd, lcm`

## Code Example
```verscript
display hcf(36, 60)  ! Outputs 12
```
