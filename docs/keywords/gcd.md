# gcd — Greatest Common Divisor

**Category:** Built-in Math Function  
**Identifier:** `gcd`

---

## Summary
Computes the largest positive integer that divides two given integers without a remainder.

## Syntax
```verscript
gcd(a, b)
```

**Parameters:** a (int), b (int)  
**Returns:** int (greatest common divisor)  
**Paired Keywords:** `lcm, hcf`

## Code Example
```verscript
display gcd(48, 18)  ! Outputs 6
```
