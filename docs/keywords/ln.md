# ln — Natural Logarithm (Base e)

**Category:** Built-in Math Function  
**Identifier:** `ln`

---

## Summary
Computes the natural logarithm (base e) of a positive number.

## Syntax
```verscript
ln(x)
```

**Parameters:** x (positive num)  
**Returns:** num (natural logarithm)  
**Paired Keywords:** `exp, log, log2`

## Code Example
```verscript
display ln(2.71828)  ! Approximately 1.0
```
