# sign / sgn — Signum Function

**Category:** Built-in Math Function  
**Identifier:** `sign`

---

## Summary
Extracts the sign of a number, returning -1 for negative numbers, 0 for zero, and +1 for positive numbers.

## Syntax
```verscript
sign(value) or sgn(value)
```

**Parameters:** value (num)  
**Returns:** int (-1, 0, or 1)  
**Paired Keywords:** `clamp`

## Code Example
```verscript
display sign(-42)  ! Outputs -1
display sgn(10)   ! Outputs 1
```
