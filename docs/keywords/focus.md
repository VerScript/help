# focus — Direct Viewport or Pane Focus

**Category:** UI / Terminal Focus  
**Identifier:** `focus`

---

## Summary
Directs keyboard and cursor focus to a specified UI element, window pane, or terminal view.

## Syntax
```verscript
focus(pane_identifier)
```

**Parameters:** pane_identifier (str)  
**Returns:** None  
**Paired Keywords:** `terminal, screen`

## Code Example
```verscript
terminal.focus("output-pane")
```
