# fill — Surface Fill Color Specification

**Category:** Style Specification  
**Identifier:** `fill`

---

## Summary
Applies solid color, gradient, or texture fill to a 2D shape or material.

## Syntax
```verscript
fill color_value or ?fill=#hex
```

**Parameters:** color_value (hex, rgb, or color name)  
**Returns:** Applies fill style  
**Paired Keywords:** `stroke, draw, rect`

## Code Example
```verscript
draw circle(100, 100, 40) ?fill=#BD00FF
```
