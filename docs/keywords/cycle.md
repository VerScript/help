# cycle — VerScript Language Keyword

> **Category**: `keyword` | **Subcategory**: Iteration

## Overview
Cycles through elements in an array or collection indefinitely or for a range.

## Syntax
```verscript
cycle <item> in <arr>:
  <body>
```

## Example
```verscript
cycle color in ["red", "green", "blue"]:
  display color
```
