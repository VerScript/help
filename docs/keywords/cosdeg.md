# cosDeg / cosdeg — Trigonometric Cosine (Degrees)

**Category:** Trigonometric Function  
**Identifier:** `cosDeg`

---

## Summary
Computes the cosine of an angle directly specified in degrees.

## Syntax
```verscript
cosDeg(degrees)
```

**Parameters:** degrees (num)  
**Returns:** num (-1.0 to 1.0)  
**Paired Keywords:** `sinDeg, degToRad`

## Code Example
```verscript
display cosDeg(0)  ! Outputs 1
```
