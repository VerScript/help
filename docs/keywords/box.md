# box — 3D Cuboid Mesh Primitive

**Category:** 3D Mesh Primitive  
**Identifier:** `box`

---

## Summary
Constructs a 3D cuboid mesh with width, height, and depth dimensions.

## Syntax
```verscript
box(width, height, depth)
```

**Parameters:** width (num), height (num), depth (num)  
**Returns:** 3D mesh object  
**Paired Keywords:** `sphere, spawn, scene`

## Code Example
```verscript
crate : box(2, 2, 2)
```
