# cos — Trigonometric Cosine (Radians)

**Category:** Trigonometric Function  
**Identifier:** `cos`

---

## Summary
Computes the trigonometric cosine of an angle in radians.

## Syntax
```verscript
cos(radians)
```

**Parameters:** radians (num)  
**Returns:** num (-1.0 to 1.0)  
**Paired Keywords:** `sin, tan, cosDeg`

## Code Example
```verscript
display cos(0)  ! Outputs 1
```
