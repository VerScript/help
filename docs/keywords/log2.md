# log2 — Binary Logarithm (Base 2)

**Category:** Built-in Math Function  
**Identifier:** `log2`

---

## Summary
Computes the base-2 logarithm of a positive number.

## Syntax
```verscript
log2(x)
```

**Parameters:** x (positive num)  
**Returns:** num (base-2 logarithm)  
**Paired Keywords:** `log, ln`

## Code Example
```verscript
display log2(256)  ! Outputs 8
```
