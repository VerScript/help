# odd — Odd Integer Predicate

**Category:** Numeric Predicate  
**Identifier:** `odd`

---

## Summary
Used alongside the 'is' operator to test if an integer is not divisible by 2.

## Syntax
```verscript
number is odd
```

**Parameters:** number (num)  
**Returns:** bool  
**Paired Keywords:** `is, even`

## Code Example
```verscript
idx : 7
if idx is odd:
    display "Odd index: " + idx
```
