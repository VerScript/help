# rt — Arbitrary n-th Root

**Category:** Built-in Math Function  
**Identifier:** `rt`

---

## Summary
Computes the arbitrary n-th root of a number.

## Syntax
```verscript
rt(value, n)
```

**Parameters:** value (num), n (num degree)  
**Returns:** num ($sqrt[n]{	ext{value}}$)  
**Paired Keywords:** `sqrt, exp`

## Code Example
```verscript
display rt(27, 3)  ! Cube root = 3
```
