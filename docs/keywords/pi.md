# pi — Archimedes' Mathematical Constant

**Category:** Math Constant  
**Identifier:** `pi`

---

## Summary
Standard mathematical ratio of a circle's circumference to its diameter ($approx 3.141592653589793$).

## Syntax
```verscript
pi
```

**Parameters:** None  
**Returns:** num (3.141592653589793)  
**Paired Keywords:** `tau, degToRad`

## Code Example
```verscript
circumference : 2 * pi * radius
```
