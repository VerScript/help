# even — Even Integer Predicate

**Category:** Numeric Predicate  
**Identifier:** `even`

---

## Summary
Used alongside the 'is' operator to test if an integer is divisible by 2.

## Syntax
```verscript
number is even
```

**Parameters:** number (num)  
**Returns:** bool  
**Paired Keywords:** `is, odd`

## Code Example
```verscript
count : 14
if count is even:
    display "Even count detected"
```
