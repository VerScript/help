# inf / infinity — Positive Infinity Constant

**Category:** Math Constant  
**Identifier:** `inf`

---

## Summary
Represents positive infinity in IEEE floating-point arithmetic and numeric limits.

## Syntax
```verscript
inf or infinity
```

**Parameters:** None  
**Returns:** num (Infinity)  
**Paired Keywords:** `min, max`

## Code Example
```verscript
minDist : inf
for d in distances:
    if d < minDist: minDist : d
```
