# sin — Trigonometric Sine (Radians)

**Category:** Trigonometric Function  
**Identifier:** `sin`

---

## Summary
Computes the trigonometric sine of an angle given in radians.

## Syntax
```verscript
sin(radians)
```

**Parameters:** radians (num)  
**Returns:** num (-1.0 to 1.0)  
**Paired Keywords:** `cos, tan, sinDeg`

## Code Example
```verscript
display sin(pi / 2)  ! Outputs 1
```
