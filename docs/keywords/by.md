# by — VerScript Language Keyword

> **Category**: `keyword` | **Subcategory**: Iteration Step

## Overview
Specifies the stride increment or decrement for a range loop.

## Syntax
```verscript
loop i from <start> to <end> by <step>
```

## Example
```verscript
loop i from 10 to 0 by -2:
  display i
```
