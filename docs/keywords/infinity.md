# infinity — Full Keyword for Positive Infinity

**Category:** Math Constant  
**Identifier:** `infinity`

---

## Summary
Represents positive infinity in numeric computations and upper limits.

## Syntax
```verscript
infinity
```

**Parameters:** None  
**Returns:** num (Infinity)  
**Paired Keywords:** `inf, min, max`

## Code Example
```verscript
val : infinity
if x < val: display "Within bounds"
```
