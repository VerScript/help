# ceil — Ceiling Rounding

**Category:** Built-in Math Function  
**Identifier:** `ceil`

---

## Summary
Rounds a numeric floating-point value upward to the nearest integer.

## Syntax
```verscript
ceil(value)
```

**Parameters:** value (num)  
**Returns:** num (ceiling integer)  
**Paired Keywords:** `floor, round`

## Code Example
```verscript
val : 4.12
display ceil(val)  ! Outputs 5
```
