# sgn — Signum Function Alias

**Category:** Built-in Math Function  
**Identifier:** `sgn`

---

## Summary
Returns -1 for negative numbers, 0 for zero, and +1 for positive numbers.

## Syntax
```verscript
sgn(value)
```

**Parameters:** value (num)  
**Returns:** int (-1, 0, or 1)  
**Paired Keywords:** `sign, clamp`

## Code Example
```verscript
display sgn(-15)  ! Outputs -1
```
