# lcm — Least Common Multiple

**Category:** Built-in Math Function  
**Identifier:** `lcm`

---

## Summary
Computes the smallest positive integer that is divisible by both given numbers.

## Syntax
```verscript
lcm(a, b)
```

**Parameters:** a (int), b (int)  
**Returns:** int  
**Paired Keywords:** `gcd, hcf`

## Code Example
```verscript
display lcm(12, 15)  ! Outputs 60
```
