# terminal — Console & Terminal Subsystem Controller

**Category:** Terminal Control  
**Identifier:** `terminal`

---

## Summary
Accesses terminal control properties, cursor navigation, clear screen, and ANSI buffers.

## Syntax
```verscript
terminal.clear(), terminal.title(str)
```

**Parameters:** Terminal commands and methods  
**Returns:** Terminal controller  
**Paired Keywords:** `display, flush, focus`

## Code Example
```verscript
terminal.title("VerScript Studio Server")
terminal.clear()
```
