# then — Consequent Conditional Action

**Category:** Conditional Clause  
**Identifier:** `then`

---

## Summary
Specifies the immediate execution statement following an if condition on the same line.

## Syntax
```verscript
if condition then statement
```

**Parameters:** condition (bool), statement (action)  
**Returns:** Statement result  
**Paired Keywords:** `if, else`

## Code Example
```verscript
score : 95
if score >= 90 then display "Honor Roll!" ?color=#00FFCC
```
