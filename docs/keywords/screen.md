# screen — Canvas & Viewport Surface Descriptor

**Category:** Graphics Canvas  
**Identifier:** `screen`

---

## Summary
Configures and accesses the graphics display surface resolution, refresh rate, and pixel buffers.

## Syntax
```verscript
screen(width, height, title)
```

**Parameters:** width (int), height (int), title (str)  
**Returns:** screen canvas context  
**Paired Keywords:** `render, draw, pixel`

## Code Example
```verscript
screen(800, 600, "VerScript 2D Sandbox")
```
